# Шаблоны текстов

Стиль: по-русски; числа с пробелами по разрядам и десятичной запятой (`1 040 с`, `0,807 с`); ключевые цифры — жирным; код,
таблицы, поля и страницы — в обратных кавычках; каждое утверждение о коде — с `file:line`. Страницы — без значений параметров
(`/catalog/1050/?from=…`), примеры — через `HIT_ID`. Перед отправкой — `pii_check.php` (раздел «Данные клиентов» в SKILL.md).
